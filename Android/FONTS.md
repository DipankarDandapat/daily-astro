# Bundled fonts

`app/src/main/res/font/` bundles fonts from [Google Fonts](https://github.com/google/fonts), licensed under the [SIL Open Font License 1.1](https://openfontlicense.org):

- Poppins (Regular, Medium, SemiBold, Bold) — Copyright 2020 The Poppins Project Authors
- Playfair Display (variable) — Copyright 2017 The Playfair Display Project Authors

Indic scripts fall back to the system Noto fonts.
